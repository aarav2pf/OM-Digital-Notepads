# Digital Notepad

Digital Notepad is a web-based system for Outstation Management to digitally record and manage visiting teams.

## Tech Stack

### Frontend
- React
- Vite
- Plain CSS

### Backend
- Node.js
- Express
- PostgreSQL
- Supabase

### Authentication
- Supabase Auth
- Google OAuth
- Superadmin allowlist

### Deployment
- Frontend: Vercel
- Backend: Render
- Database & Authentication: Supabase
